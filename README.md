# DCG Recon

DCG Recon is a modern application designed to provide a user-friendly interface for managing RCN Receivers. Inspired by Roberts Communications Network's original "Recon" application, DCG Recon offers an improved and streamlined experience for interacting with RCN Receivers, allowing users to change channels, modify receiver settings, and access schedule data with ease.

## Features

- **Modern Interface**: A sleek and intuitive design for easier navigation and operation.
- **Receiver Management**: Communicate with RCN Receivers to change channels and modify settings.
- **Schedule Data**: Display and interact with schedule data from RTN's website.
- **Enhanced Functionality**: Additional tools and options not available in the original Recon application.

## Getting Started

To get started with DCG Recon, follow these steps:

1. **Download and Install**: Download the latest version of DCG Recon from the releases section.
2. **Setup**: Follow the installation instructions provided in the setup guide.
3. **Configure Receivers**: Connect and configure your RCN Receivers within the application.
4. **Access Schedule Data**: View and interact with the schedule data directly within DCG Recon.

## Requirements

- Windows 7 or later
- .NET 6.0 or later
- .NET Framework 4.7.2 or later
- Active internet connection for accessing schedule data

## Usage

1. **Launch the Application**: Open DCG Recon from your start menu or desktop shortcut.
2. **Connect to Receivers**: Use the interface to connect to your RCN Receivers.
3. **Manage Channels and Settings**: Easily change channels and modify receiver settings.
4. **View Schedule**: Access the latest schedule data from RTN and plan your viewing.
